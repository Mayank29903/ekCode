## Prompt 03 — ML package `backend/ekml/` (2026-09-30)

**Added**
- `ekml/__init__.py`, `normalize.py`, `extract.py`, `embed.py`, `features.py`, `gates.py`, `score.py`, `explain.py`, `standardize.py`, `nmc.py`, `taxonomy.py`, `llm.py`, `train.py`, `dictionaries/abbreviations.yaml`, `nouns.yaml`, `units.yaml`.

**Fixes to the reference code**
- `units.yaml`: YAML reads the unquoted key `no` as boolean `False`, so the unit "NO" never mapped to `C62`. Now quoted; more Rec 20 units added.
- Grade: `SS316L` was cut to `SS316` (and `A182 F316L` to `F316`), so 316 and 316L could merge. The `L` suffix is kept unless it is a length marker (`SS316 L50`). `304 SS` is recognized; `CF8M` works after normalization. `A106 GR.B` and `A106B` compare equal.
- Bolts written without `M` (`Bolt hexagonal SS 12x50mm`, the ONGC row in the PRD) had no thread or length. Diameter × length is now read for bolts.
- Pipe sizes: `50 NB`, `DN 50`, `NPS 2` and `1-1/2"` all map to the same `size_in`, so metric and inch descriptions of one pipe can match.
- Noun detection: "bolt for flange" and "flange gasket" were detected as FLANGE. Text after "for"/"with" is ignored, and FLANGE and PIPE are marked weak. New nouns: STUD BOLT, GLOBE/CHECK/BUTTERFLY VALVE, TEE, REDUCER, OIL SEAL, O-RING, so stud vs hex bolt and tee vs elbow are blocked by the noun gate. The generic `seal` keyword was removed.
- Bearing numbers were only found when the number came before the word "bearing"; `6205-2RS` and `6205 2RS` now compare equal. Cable and bearing attributes are only extracted for those nouns.
- `API 6D` lost its `D`; `sch-40` and `cl150` weren't recognized; `1-1/2"` became `0.5 in`.
- Numbers are canonical (`50.0` = `50`), so formatting can't trip a gate.
- Attribute feature: a value stated on only one side now counts 0.5 instead of being ignored, as the PRD says.
- Exact duplicate: token-set similarity scores a subset as 100%, so "BOLT M12" vs "BOLT M12 X 50 SS304" could be an exact duplicate, which is eligible for auto-approve. It now needs same words, every attribute on both sides, and no unit conflict (new non-model feature `text_exact`).
- Standard description: `GATE VALVE` became `GATE, VALVE`; now `VALVE, GATE` (noun first).
- LLM: `import hashlib, json, os, re` fails ruff (E401). Values are now validated per key and put through the regex extractor, so an LLM `316` becomes `SS316` instead of tripping the grade gate. Added `fill_gaps()` (never overwrites regex values), a bounded cache, and default URLs.
- NMC: `make_nmc` rejects a non-numeric category or out-of-range serial; `is_valid` checks the `NMC` prefix.
- Taxonomy: file read as UTF-8 and closed properly; the embedding cache is rebuilt when stale; accepts a precomputed vector to avoid re-embedding during ingest.
- Train: refuses fewer than 5 of either label, where StratifiedKFold would crash; metrics are plain floats.
- PRD worked example and glossary now show the real description format.

**Checks**
- Prompt 03 check passes: thread 12 in a and b, `gate_failures(a, b) == []`, `gate_failures(a, c) == ['thread']`.
- Also passing: 14 extraction cases, all five G2 hard negatives blocked (M12/M16, 150#/300#, SS304/SS316, SS316/SS316L, stud/hex bolt), UoM mapping, NMC check digits, LLM output validation.

## Prompt 05 — Ingest pipeline, matching, clustering, NMC, workers, review (2026-09-30)

**Added**
- `backend/app/services/ingest_service.py`, `match_service.py`, `nmc_service.py`, `cluster_service.py`, `sap_service.py`, `webhook_service.py`; `app/workers/queue.py`, `jobs.py`; `app/routers/ingest.py`, `review.py`. `main.py` now registers ingest and review.
- `test_upload_IOCL.csv`, `test_upload_ONGC.csv` in the project root, from the testing guide.

**Changes from the reference**
- Ingestion:
  - Upserts run in batches of 1,000 instead of one statement per row.
  - Re-uploading an unchanged file no longer resets every row to `ingested` and re-embeds it. Rows whose text and unit are unchanged keep their status; price, quantity and group are still refreshed.
  - A code repeated within one file used to crash the batch; now the last row wins and a warning is recorded.
  - Codes over 60 characters are reported as errors instead of failing the insert.
  - Numbers like `₹ 1,250.00` are parsed.
- File reading:
  - UTF-8 with a BOM and Windows-1252 files (the usual Excel "Save as CSV") are detected.
  - Delimiter detection covers `,` `;` tab and `|`, and `.txt`/`.tsv` are accepted.
  - Headers are trimmed.
  - `.xls` was accepted but couldn't be read, so `xlrd` was added to `pyproject.toml`.
- Pipeline stages: `normalizing` was never reported; each stage is now announced before its first batch. Processed rows are dropped from the SQLAlchemy identity map, so a 50k-row job doesn't hold every embedding in memory.
- Matching:
  - Each pair is scored once per run.
  - A re-scored pair now also updates its `status`. Previously a pair that newly failed a gate stayed `suggested`.
  - Impact uncertainty is centred on the configured `near` threshold, not a hard-coded 0.85.
  - A missing model file falls back to the weighted formula instead of silently using the previous model.
- Auto-approve (ADR-19): respects the auto threshold, locks each pair, and a merge conflict skips that pair instead of failing the whole ingest job. Auto-approvals also send webhooks.
- Approve transaction:
  - The two material rows are locked in id order, so concurrent approvals that touch the same material can't both issue codes.
  - Every legacy code remapped by a merge now gets its own audit row (G4).
  - A missing pair returns 404 instead of 500, and `reject_pair` works for a system actor.
- NMC issuance: reuses the stored embedding for the UNSPSC lookup, so the API process never loads the model. The category prefix is checked to be 4 digits before it is used in the sequence name (SQL identifier safety). Sequences have `MAXVALUE 999999`.
- Routers:
  - Uploads are capped (`MAX_UPLOAD_MB`, default 100); unreadable or empty files get a clear 400.
  - `start` refuses to double-queue, checks the mapped columns exist in the file, and marks the job `error` with 503 if Redis is down.
  - CPSE users only see their own CPSE's jobs.
  - SSE returns 404 for an unknown job (otherwise EventSource reconnects forever) and sends a keep-alive every 15 s.
  - The review queue loads both sides of all pairs in three queries instead of three per side, pages with `offset`, and sorts the approved/rejected tabs by decision time.
  - Decisions are validated (`approve` | `reject`, reason ≤ 500 characters). Bulk actions lock each pair and are capped at 500.
  - Webhook enqueue failures are logged instead of turning a committed decision into a 500.
- `ekml/extract.py`: `B16.20` and `ASME B16.20` are now the same standard. Found through the test CSVs, where IOCL and ONGC write the gasket standard differently.
- SAP export: cells starting with `=`, `+`, `-` or `@` are escaped against spreadsheet formula injection; unknown CPSE gives 404; `test_connection` reports network and non-JSON errors instead of raising.
- Kept from the reference, now documented in FLOW.md §6: gate-blocked pairs are used as negative training labels.

**Not run here** (nothing is executed on this laptop): the Docker, `/api/docs` and worker checks for prompts 04 and 05.

## Robustness pass (2026-09-30)

A re-read of the whole project for wrong results, concurrent users, bad files, outages and security gaps. The API contract is unchanged; the only additions are listed below.

**Added**
- `POST /api/v1/auth/password`: users change their own password from the key icon in the top bar. The current password is checked, attempts are throttled, and the change is audited.
- Session revocation: every token carries `pv`, a fingerprint of the password hash. A password change or an admin reset signs out every other session; the browser that made the change stays signed in, including an admin who resets their own password under Settings → Users.
- Stalled jobs:
  - New column `ingest_job.updated_at`, added automatically by `init_db` on existing databases.
  - A queued or running job with no progress for `STALE_JOB_MINUTES` (default 30) shows as *stalled* with a **Restart** button.
  - `/start` locks the job row, so two clicks cannot queue it twice, and returns 410 if the uploaded file is gone.
- Security headers:
  - Nginx sends a Content-Security-Policy with no inline scripts; the theme script moved to `public/theme-init.js`. It also sends Permissions-Policy and Cross-Origin-Opener-Policy.
  - API responses carry `Cache-Control: no-store`.
- Error pages: a page that crashes, or an old tab that cannot load the code of a newer release, shows a friendly message with **Reload**, inside the app shell. Before, React Router showed its developer error page.
- Settings: `DOCS_ENABLED`, `LOG_LEVEL` and `STALE_JOB_MINUTES`. They are documented in `.env.example` together with `MAX_UPLOAD_MB`.

**Changed: matching (`ekml`)**
- Lengths are read with their unit:
  - `L=6M` → 6000 mm.
  - `L 6000MM` → 6000 mm, and the 6000 is no longer also taken as a size.
  - Values are computed with `Decimal`, so 1.005 m is exactly 1005 mm.
- European `PN16` ratings are extracted and never equal an ASME class, so `150#` vs `PN16` is a hard-gate conflict.
- `CL150 1/2 IN` reads as 0.5 in, not 150.5 in.
- The shipped dictionary gains plurals (studs, gaskets, valves …) and finishes (galv, hdg, zp).
- The dictionary is swapped in one step, so a running request never sees half of it. Regexes and noun keywords are compiled once.
- LLM:
  - Only rows the rules could not read are sent to it.
  - Successful answers are cached.
  - After 5 failures in a row the provider is paused for 5 minutes.
  - Any failure, such as a mistyped URL, falls back to the rules instead of failing the upload.
- Embedding and taxonomy:
  - The embedding model loads once per process, even under concurrent first requests.
  - The UNSPSC index reloads when the code list file changes.
  - The UNSPSC vector cache is kept per embedding model, so changing `EMBED_MODEL` can never mix vector sizes.

**Changed: backend**
- Concurrency:
  - "Issue codes for unique materials" takes an advisory lock.
  - NMC sequences are created on a separate autocommit connection.
  - A unique violation, deadlock or serialization failure returns 409 with a friendly message; an unreachable database returns 503.
  - Bulk review and auto-approve skip a pair that someone else decided at the same moment.
- Settings fall back to the defaults key by key (`settings_store.thresholds()` / `flags()`), so a partial settings row cannot break matching.
- An unreadable model file falls back to the weighted formula instead of failing every upload.
- Uploads:
  - "NA", "N/A" and "NULL" stay literal.
  - Lines with a stray delimiter are skipped and listed in the report instead of failing the file; the upload response reports `bad_lines`.
  - Changed rows are detected NULL-safely (`IS DISTINCT FROM`).
- The SAP pull pages through `A_Product` 500 products at a time.
- Webhooks:
  - Each event fans out to one job per hook.
  - Every delivery carries an `id`, `sent_at` and an `X-EkCode-Delivery` header.
  - Redirects are not followed.
  - A failed delivery is retried after 10 s, 1 min and 5 min. The worker now runs `rq worker --with-scheduler`.
- The login throttle's memory is bounded; password changes are throttled too.
- Index on `national_material.successor_nmc`. An invalid `LOG_LEVEL` falls back to INFO instead of stopping the API.

**Changed: frontend**
- API client:
  - Plain-language messages for a network failure, 502/503/504 and 413.
  - 204 responses and broken bodies are handled.
  - No retries on 400/401/403/404/409/410/422.
  - The progress stream now respects `VITE_API_URL` like every other request.
- Upload page:
  - **Restart** / **Try again** for stalled or failed jobs, and a "stalled" badge.
  - A warning about skipped lines.
  - A clear state for files that were uploaded but never started.
  - The progress stream resets for a new job and stops polling on 401/403/404.
- Review: approve/reject are disabled while the next page of pairs is loading, so a steward cannot decide a pair they have not seen.
- Hotkeys ignore auto-repeat and do nothing while a dialog is open.
- Pages whose data has not arrived show the loader (`isPending`) instead of crashing when the browser is offline.
- Knowledge graph: React Flow manages the node state, so nodes can be dragged apart.
